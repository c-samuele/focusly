# Documentation

Struttura corrente della documentazione:

- `notes/` contiene note tecniche, configurazione generica e refactor interni;
  `notes/private/` è riservata a note locali non versionate
- `Relazione/` contiene i sorgenti LaTeX e gli elaborati di progetto

I file LaTeX generati (`.aux`, `.log`, `.out`, ecc.) non vanno mantenuti nel repository.
